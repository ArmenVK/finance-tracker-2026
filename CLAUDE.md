# Мои финансы 2026

Личный финансовый трекер — один статичный файл `index.html` (таблица доходов/расходов), без JS и backend. Данные хранятся прямо в HTML-разметке и правятся вручную по запросу.

## Правила

- **Разрешён только один инлайн `<script>` для формы добавления записи.** Проект — HTML-файл с таблицей и формой ввода (дата, категория, сумма), данные добавленных записей хранятся в `localStorage`. Backend, сборка, внешние библиотеки/CDN — по-прежнему запрещены.
- **`localStorage` — не бэкап и не синхронизация.** Записи, добавленные через форму, видны только в том браузере/профиле, где их ввели. При открытии файла в другом браузере или после ручного редактирования `index.html` эти записи не появятся сами по себе.
- **Новые строки — по хронологии.** При добавлении записи вставлять `<tr>` в `<tbody>` на нужное место по дате (ДД.ММ.ГГГГ), а не в конец таблицы.
- **Доходы и расходы различаются знаком.** Перед суммой: `+` для дохода, `−` для расхода (например, `-4 250 ₽`, `+120 000 ₽`). Итог в `tfoot` — алгебраическая сумма всех строк с их знаками, а не сумма модулей.
- **Формат чисел и дат** — как в текущей таблице: дата `ДД.ММ.ГГГГ`, сумма с пробелом как разделителем тысяч и символом `₽` после числа.
- **Категории свободные, но без дублей по смыслу.** Перед созданием новой категории (например, «Транспортные расходы») проверить, нет ли уже похожей существующей («Транспорт») — использовать существующую, если она покрывает случай.
- **Бэкапы не нужны.** Файл не под git, можно править `index.html` напрямую без сохранения копий перед изменением.
